# melancholy Studio — обновления Blender

Канал обновлений дополнения для подготовки DFF и профилей физики.
**Приватных моделей, DFF, TXD, .blend и профилей пользователей здесь нет.**

## Первичная установка

Скачать `melancholy_studio_blender_1.1.0.zip` из этого репозитория.
В Blender: Preferences → Add-ons → Install from Disk, выбрать ZIP без распаковки,
включить melancholy Studio. При обновлении со старой ручной версии сначала удалить
старое дополнение и полностью перезапустить Blender.

## Последующие обновления

В панели N → melancholy или в настройках дополнения доступны кнопки
**Проверить обновления → Установить обновление**.
Проверка при запуске включена по умолчанию; её можно выключить в настройках.
Доступ в сеть должен быть разрешён настройками Blender.
После установки сохранить проект и перезапустить Blender.
До перезапуска действует уже загруженная версия кода.

Загружаются только update.json и ZIP дополнения по HTTPS из этого репозитория.
Перед заменой проверяются SHA-256, структура архива, синтаксис Python и версия.
Старые файлы сохраняются рядом с каталогом дополнения в
`.melancholy_update_cache/update-…/previous`. При ошибке замены восстанавливаются.
Проекты и модели не передаются на GitHub и не заменяются обновлением.
Это обновление **дополнения Blender**, не игрового ASI и не моделей.

## Выпуск новой версии без нейросети

1. Отредактировать исходники дополнения (они открыто лежат внутри устанавливаемого ZIP).
2. Увеличить `bl_info['version']` в `melancholy_studio/__init__.py`.
3. Проверить экспорт на своей модели.
4. Выполнить обычным Python:
   ```sh
   python build_addon_update.py --source путь/к/melancholy_studio --output update_dist --notes "Описание исправлений"
   ```
5. На GitHub → Add file → Upload files загрузить вместе новый ZIP и update.json
   из update_dist и сохранить коммит в main. Старые ZIP удалять необязательно.
6. У пользователей следующая проверка покажет новую версию.

SHA-256 защищает от повреждения или несовпадения файлов; доверие к издателю
обновлений основано на HTTPS и доступе владельца к этому GitHub-репозиторию.
